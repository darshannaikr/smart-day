# Smart Day

A full-stack calendar and productivity application built using Java,
Spring Boot, Microservices, React, PostgreSQL, and modern cloud-native
technologies.

## Tech Stack

### Backend
- Java 17
- Spring Boot
- Spring Security
- JPA / Hibernate
- PostgreSQL
- Apache Kafka
- Redis

### Frontend
- React
- JavaScript / TypeScript
- React Router
- Redux Toolkit

### DevOps
- Git
- GitHub
- Docker
- GitHub Actions
